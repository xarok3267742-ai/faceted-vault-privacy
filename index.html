Об игре и данных

«Гранёный свод: слоты» — бесплатная игра для взрослых с виртуальными очками, слотами и мозаиками минералов. Денежных ставок, депозитов, покупок, вывода денег и материальных призов нет. Учётная запись не нужна. Основной игровой процесс выполняется на устройстве без подключения к серверу разработчика. В приложении нет рекламы, аналитики и автоматической отправки отчётов разработчику. Игровые данные не собираются разработчиком и не передаются ему.

В закрытой папке приложения на устройстве сохраняются виртуальные очки, число и результаты раундов, бонусы, выбранная ставка, настройки звука, вибрации и движения, отметка о подтверждении совершеннолетия. Для мозаик дополнительно сохраняются выбранный символ фокуса, полученные инструменты, расположение фрагментов, выделенный фрагмент и собранные образцы. Эти сведения нужны для продолжения игры с прежнего места; они не обмениваются на деньги и не передаются другим игрокам. Приложение не запрашивает дату рождения и не проверяет документы.

Разрешения и хранение

Приложение использует разрешение на вибрацию только для игрового отклика; вибрацию можно выключить в настройках. Звук воспроизводится локально. Микрофон, камера, контакты, геопозиция и рекламный идентификатор не используются. Автоматическое резервное копирование данных приложения отключено. При распространении через Google Play сам магазин может проверять источник установки согласно своим условиям; это не передаёт игровое сохранение разработчику.

Локальные данные остаются до очистки данных приложения или его удаления. Для удаления откройте настройки Android → приложения → «Гранёный свод: слоты» → хранилище → очистить данные либо удалите приложение. Названия пунктов могут отличаться на устройствах. Серверной копии прогресса нет.

Если сохранение повреждено, приложение предлагает восстановление. Только после подтверждения прежние данные копируются в локальный recovery-файл и создаётся новое сохранение. Эта копия не отправляется наружу и удаляется при очистке данных приложения или его удалении. Само восстановление с копией не означает полного удаления данных.
